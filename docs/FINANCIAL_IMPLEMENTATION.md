# Luna financial module (first implementation)
The owner-approved financial directive is stored at `docs/FINANCIAL_DIRECTIVE_V1.json`.
`luna.financial` loads and validates that policy, evaluates hypothetical opportunity estimates,
calculates bookkeeping snapshots, and refuses to treat spending requests as authorized.
No payment accounts, credentials, tax filing, transactions, autonomous customer contact,
live revenue, or financial permissions are added. All estimates are user-provided or hypothetical,
not market research. This is a tested planning foundation, not a revenue-producing business.
Next integration requires owner-reviewed database schema, authenticated access, immutable
approval/audit records, and independently enforced monetary limits.
