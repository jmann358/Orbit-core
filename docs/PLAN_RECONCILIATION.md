## Update-path finding

The installed service runs a detached ee067a3 checkout under Application
Support. Its LaunchAgent invokes start_luna_agent.py, not verify_and_launch.sh;
normal service restart does not pull or merge source. The verified-main
launcher rejects a non-main branch before importing application code. This
blocks an accidental legacy update path; it is not yet a candidate-updater.

Do not switch the installed checkout to main to bypass that guard. Future
promotion needs a reviewed exact commit, compatible runtime/schema, consistent
backup, stopped writer, rollback checkpoint and post-install acceptance.
